# Музыкальный бот для Discord — как запустить

## Какие файлы нужны
В одной папке должны лежать:
- `bot.py` — сам бот;
- `requirements.txt` — список библиотек;
- папка `config` с настройками (если её нет — бот создаст сама при первом запуске);
- `patchnotes.txt` — что нового в боте (бот сам публикует патчноуты, см. раздел «Патчноуты»);
- папка `miniapp` — страница мини-приложения игр `/wort` и `/slovo` (см. раздел «Wortjagd»);
- `start.example.bat` — шаблон файла запуска для Windows (см. шаг 4);
- `.gitignore` — если выкладываете проект на GitHub, он не даст загрузить туда ключи (`start.bat`) и базу (`levels.db`);
- картинки фонов (необязательно): `rank_bg.jpg`, `leaderboard_bg.jpg` и другие — см. раздел «Фоны картинок».

Ключи и токены в файлах бота не хранятся — их задают при запуске (см. ниже).

Что понадобится:
- **токен бота** Discord (Developer Portal → вкладка Bot → Reset Token);
- ключи Spotify — необязательно: ссылки Spotify на треки, альбомы и плейлисты работают и без них
  (бот берёт список треков со страницы плеера Spotify; с ключами треки и альбомы читаются через API).
  Плейлист должен быть публичным, из него берутся первые 100 треков;
- ключ Gemini — необязательно (без него не будет ИИ: `/ask` и ответов на упоминание).
  Ключ бесплатно выдаётся на https://aistudio.google.com/apikey

## Запуск на Windows

### 1. Установить Python 3.13
Нужен именно **3.13** (на 3.15 нужная библиотека пока не ставится). В командной строке (cmd):
```
winget install Python.Python.3.13
```
Проверить: `py --version` — должно быть `Python 3.13.x`. Если показывает другую версию,
дальше везде писать `py -3.13` вместо `py`.

### 2. Установить программы для музыки
```
winget install ffmpeg
winget install --id=DenoLand.Deno
```
После установки **закрыть cmd и открыть заново**.

### 3. Установить библиотеки
Открыть cmd в папке с ботом: в Проводнике кликнуть по адресной строке, написать `cmd`, нажать Enter. Затем:
```
py -m pip install -U -r requirements.txt
```
В конце должно появиться `Successfully installed ...`.

### 4. Создать файл запуска start.bat
В папке бота есть шаблон `start.example.bat`. Скопируйте его, назовите копию `start.bat`, откройте её
Блокнотом (правая кнопка → «Изменить») и замените только то, что после `=`. Внутри такой текст:
```
@echo off
chcp 65001 >nul
set DISCORD_TOKEN=сюда_токен_бота
set SPOTIFY_CLIENT_ID=сюда_client_id
set SPOTIFY_CLIENT_SECRET=сюда_client_secret
set GEMINI_API_KEY=сюда_ключ_gemini
set DISCORD_CLIENT_SECRET=сюда_client_secret_приложения
cd /d "%~dp0"
py bot.py
pause
```
Без пробелов вокруг `=` и без кавычек. Строки с ключами, которых нет, можно удалить.

**Никому не пересылать `start.bat` и не делать скриншотов с ключами.**

### 5. Запустить
Двойной щелчок по `start.bat`. Должно появиться «Зарегистрировано слэш-команд: 69» и «Бот запущен как …».
Пока окно открыто — бот работает. Закрыть окно = выключить бота.

## Запуск на Linux-сервере (Ubuntu/Debian)

### 1. Программы
```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip ffmpeg unzip tmux fonts-dejavu-core
curl -fsSL https://deno.land/install.sh | sh
```
После установки Deno перезайти на сервер (или выполнить `source ~/.bashrc`).

### 2. Файлы и библиотеки
```bash
mkdir ~/musicbot && cd ~/musicbot
# положить сюда bot.py, requirements.txt и картинки фонов
python3 -m venv venv
source venv/bin/activate
pip install -U -r requirements.txt
```

### 3. Запуск (бот продолжит работать после выхода с сервера)
```bash
tmux new -s musicbot
cd ~/musicbot
source venv/bin/activate
export DISCORD_TOKEN="ТОКЕН_БОТА"
export SPOTIFY_CLIENT_ID="CLIENT_ID_ИЗ_SPOTIFY"
export SPOTIFY_CLIENT_SECRET="CLIENT_SECRET_ИЗ_SPOTIFY"
export GEMINI_API_KEY="КЛЮЧ_GEMINI"
python bot.py
```
Отключиться от tmux, оставив бота работать: **Ctrl+B**, потом **D**.
Вернуться к боту: `tmux attach -t musicbot`. Остановить бота: **Ctrl+C**.

## Важно
- **Не запускать бота в двух местах одновременно** с одним токеном — команды будут ломаться.
- Рядом с `bot.py` сам появится файл `levels.db`. В нём хранятся опыт участников, очередь песен,
  статистика прослушиваний, города для погоды, результаты игры, монеты участников,
  настройки утренних и вечерних сообщений и память разговора с ИИ.
  Не удаляйте его, иначе всё обнулится. При переносе бота на другой компьютер этот файл можно
  скопировать вместе с ботом (только пока бот выключен).
- **При обновлении бота заменяйте только `bot.py`.** Папку `config` и файл `levels.db` не трогайте —
  в них ваши настройки и все данные.

## Папка config — настройки без правки кода

| Файл | Что в нём | Когда применяется |
|---|---|---|
| `config/prompt.txt` | характер ИИ, обычным текстом | сразу после сохранения |
| `config/auto_replies.txt` | автоответы: строки `слово = ответ` | сразу после сохранения |
| `config/bad_words.txt` | слова, на которые ИИ не отвечает (мат) | сразу после сохранения |
| `config/settings.ini` | модель и лимиты ИИ, запасная модель, опыт, монеты, ставки, игра | после перезапуска бота |

Файлы открываются Блокнотом, в начале каждого есть пояснения. В `auto_replies.txt` можно указать
несколько слов через запятую и несколько вариантов ответа через `|` — бот выберет случайный:
```
привет, здарова = привет милый | о, привет
```
После `||` можно написать ответ тем, кто за последние сутки грубил боту: `привет = привет милый || иди нахуй`.
Звёздочка на конце слова — любые буквы (`дот*` — «дота», «доту», «дотой»). Срабатывает первая подходящая строка.
Строка с `~` в начале — приветствие: если оно адресовано другому («привет саня», «привет @кто-то», ответ на чужое
сообщение, ник того, кто писал в чат), бот промолчит. На свои имена («привет малфоид», «hallaan») отвечает всегда —
их список в `settings.ini`, раздел `[names]`, строка `bot_names`.
Правила оформления формул и памяти ИИ бот добавляет к характеру сам — в `prompt.txt` их писать не нужно.
Если в `settings.ini` ошибиться, бот возьмёт значение по умолчанию и напишет об этом в консоль.

**Грубость.** Если к боту обращаются с матом (упоминание, ответ на его сообщение или `/ask`), он молча
не отвечает. Сначала бот проверяет слова из `bad_words.txt` (это не тратит запросы к Google), а
замаскированный мат («х*й»), оскорбления и непотребства без матных слов распознаёт сам ИИ.
Каждый такой случай записывается в `bot.log`.

**Тайм-ауты за грубость.** Первый раз бот просто молчит. Если человек грубит боту второй раз подряд —
тайм-аут на 1 минуту, третий — 5 минут, дальше 10, 30, 60 (и потом каждый раз 60). Бот пишет об этом
в чат и в канал логов (`/log_channel`). Счётчик обнуляется, если человек нормально обратился к боту
или час не грубил. Всё это настраивается в `settings.ini`, раздел `[moderation]`: `timeouts`
(минуты через запятую, `off` — без тайм-аутов), `strike_reset_minutes`, `announce_timeouts`.

Чтобы тайм-ауты работали, боту нужно право **«Отправлять участников подумать» (Moderate Members)**,
а его роль должна стоять выше ролей участников. Владельцу сервера и администраторам Discord тайм-аут
дать не позволяет — бот только промолчит и напишет об этом в канал логов.

**Варны и тайм-ауты по просьбе модератора.** Модератор может попросить бота словами: «@бот дай варн @Вася за
спам», «@бот кинь @Петю в тайм-аут на час», «@бот сними тайм-аут с @Пети» (или ответить на сообщение нарушителя
с упоминанием бота: «@бот замуть его на 10 минут»). Срок не назвали — 10 минут. Бот слушается только тех, у кого
есть право «Отправлять участников подумать» (Moderate Members) или права администратора, и не наказывает ботов,
владельца сервера и тех, чья роль не ниже роли модератора. Обычному участнику бот откажет. Варны смотреть —
`/warns`, снять — `/warns_clear` (видна модераторам). Каждое наказание дублируется в канал логов.
Варны наказывают и сами: по умолчанию 3-й варн — тайм-аут на час, 5-й — на сутки, 7-й и дальше — на неделю.
Пороги — `settings.ini`, раздел `[moderation]`, строка `warn_punishments` (`off` — только записывать варны).

**Ответы другим ботам.** Бот отвечает другому боту, только если тот прямо пингует его или отвечает на его
сообщение, и не больше 3 раз подряд в канале — потом молчит, пока туда не напишет живой человек. Так два бота
с ИИ не будут переписываться бесконечно. Настройки в `settings.ini`: `reply_to_bots` (`off` — не отвечать
ботам совсем) и `bot_reply_limit`. Опыт и автоответы ботам не положены.

**Если Google перегружен (ошибка 503).** Бот повторяет запрос ещё `retries` раз (по умолчанию 2, с паузой
2 и 4 секунды), а если основная модель так и не ответила — или у неё кончился лимит — спрашивает запасную
`fallback_model` (по умолчанию `gemini-3.8-flash`; `none` — без запасной). Обе строки — в `settings.ini`.

## Канал для рангов, рейтингов и игр
Команда `/games_channel` (видна тем, кто может управлять сервером) выбирает канал, в котором работают
`/rank`, рейтинги, игры и экономика. В других каналах бот тихо подскажет, куда идти. Вызвать `/games_channel`
без канала — снова разрешить везде. Какие команды ограничены — строка `games_commands` в `settings.ini`.

При получении нового уровня бот ничего не пишет (уровень видно по `/rank`). Включить поздравления можно
в `settings.ini`: `level_up_message = text` (только текст) или `card` (текст и карточка).

## Логи ошибок
Все ошибки бота (ИИ недоступен, сбой Spotify, погоды, ежедневных сообщений, любой команды) пишутся
в консоль и в файл `bot.log` рядом с `bot.py` (старые записи уходят в `bot.log.1`, `bot.log.2`...).
Команда `/log_channel` (видна тем, кто может управлять сервером) выбирает канал, куда бот будет ещё и
присылать карточку с ошибкой: где она случилась, у кого и подробности. Лучше выбрать закрытый канал
только для админов. Вызвать `/log_channel` без канала — перестать присылать ошибки в Discord.

## Фоны картинок
Фоны лежат рядом с `bot.py`, по одному файлу на картинку (все необязательны — без них будет градиент):

| Картинка | Файл фона |
|---|---|
| `/rank` | `rank_bg.jpg` |
| `/leaderboard` | `leaderboard_bg.jpg` |
| `/top_chart_month` | `chart_bg.jpg` |
| `/dick_leaderboard` | `dick_bg.jpg` |
| `/money_leaderboard` | `money_bg.jpg` |

Подойдут `.jpg`, `.jpeg`, `.png`, `.webp`. Чтобы поменять фон, просто замените файл — перезапускать бота не нужно.

## Ставки в играх
В `/coinflip`, `/slots` и `/blackjack` вместо числа можно написать **all** (или «всё», «ва-банк») — поставить
все монеты разом (но не больше 1 000 000). Discord сам подскажет вариант «all» в поле ставки.

## Питомцы и кейсы
Питомцев выбивают из кейсов `/case`: 📦 дешёвый (500 монет), 🎁 средний (2000) и 💎 дорогой (7500,
в нём нет обычных питомцев). Чем дороже кейс, тем выше шанс на редкого питомца — шансы и всех питомцев
показывает `/cases`: от котика и хомяка до самого редкого — 🐶 собаки Сергея (0,01% / 0,2% / 1,5%).
Каждый питомец сам зарабатывает монеты в час — забрать их `/pets_collect` (копится не
больше 24 часов). Питомец растёт, если его кормить (`/pet_feed`, корм дорожает с каждым уровнем): каждый уровень
даёт +25% к доходу, а по пути он становится подростком, взрослым и легендой района. Посмотреть своих (или чужих)
питомцев — `/pets`, продать за половину вложенного — `/pet_sell`. Не больше 10 питомцев на человека.
Цены и лимиты — `settings.ini`, раздел `[pets]`.

## Новые команды (обновление v10)

**Музыка**
- Под сообщением «Играет» есть кнопки: ⏯ пауза, ⏭ следующий трек, 🔁 повтор текущего трека, 🔀 перемешать очередь.
  Нажимать может тот, кто сидит с ботом в одном голосовом канале.
- `/autoplay` — включить или выключить автоплей: когда очередь кончилась, бот сам подбирает похожий трек
  (берёт «микс» YouTube; работает для треков с YouTube и только пока в канале кто-то есть).
- `/playlist_save` — сохранить текущий трек и очередь как плейлист сервера, `/playlist_play` — добавить его в очередь,
  `/playlists` — список, `/playlist_delete` — удалить (для админов). До 25 плейлистов по 100 треков.
- `/lyrics` — кнопка-ссылка на текст песни (той, что играет, или по названию). Сам текст бот в чат не пишет:
  тексты песен защищены авторским правом.

**Экономика и питомцы**
- `/daily` — ежедневный бонус: 200 монет, за каждый следующий день подряд +50 (до 7 дней, то есть до 500).
  Пропустил день — серия заново. Суммы — `settings.ini`, раздел `[economy]`.
- `/shop`, `/shop_buy` — магазин ролей за монеты. Админ выставляет роль: `/shop_add роль цена дни`
  (дни = 0 — навсегда; роль на время бот снимет сам), убирает — `/shop_remove`. Боту нужно право
  «Управлять ролями», и его роль должна быть выше продаваемых. Роли с правами админа или модератора
  в магазин поставить нельзя.
- `/pet_battle` — бой на ставку: твой питомец против сильнейшего питомца соперника. Шанс победить — по доходу
  питомцев в час (от 10% до 90%). Соперник должен принять вызов кнопкой.
- `/pet_trade` — обмен питомцами: твой на чужого, второй участник подтверждает кнопкой.
- В `/pets` питомцы отсортированы: сверху тот, кто приносит больше всего монет.

**Слова**
- `/wordstats` — статистика в Wortjagd и «5 букв»: игры, победы, серия побед, с какой попытки угадываешь.
- `/wordtop` — лучшие игроки месяца картинкой. Очки: с 1-й попытки 6, со 2-й 5 … с 6-й 1.
- `/wordduel` — дуэль на монеты: оба ставят и отгадывают сегодняшнее слово дня, побеждает тот, кому хватило
  меньше попыток. Вызвать можно, только пока оба не начинали сегодняшнее слово. Не доиграл до конца дня — проиграл,
  ничья — ставки возвращаются.

**Сервер**
- `/remind 2ч проверить сервер` — напоминание в этом же канале (`30м`, `2ч`, `1д`, `1ч 30м`). `/reminders` — список,
  там же можно отменить.
- `/poll` — опрос с кнопками: вопрос и от 2 до 5 вариантов через `|`. Голос можно поменять; когда время выйдет,
  бот покажет итоги.
- **Анти-спам:** 4 одинаковых сообщения или 4 сообщения со ссылками за 20 секунд — бот удаляет их и выдаёт варн
  (а варны сами ведут к тайм-ауту). Модераторов не трогает. Чтобы удалять сообщения, боту нужно право
  «Управлять сообщениями». Пороги и выключение — `settings.ini`, раздел `[antispam]`.
- **Приветствие новичков:** `/welcome_channel #канал` — бот встречает новых участников фразой от ИИ и картинкой.
  Нужно разрешение: Developer Portal → вкладка **Bot** → включить **Server Members Intent**, потом в `settings.ini`
  в разделе `[welcome]` поставить `members_intent = on` и перезапустить бота. Именно в таком порядке:
  если включить только в `settings.ini`, бот не запустится.

**ИИ**
- `/summary` — ИИ кратко перескажет, о чём говорили в канале за последние часы (видишь только ты).
- `/quiz` — викторина: ИИ придумывает вопрос с 4 вариантами, у каждого одна попытка, первый правильный ответ
  приносит 100 монет. Можно указать тему. Награда и время — `settings.ini`, раздел `[quiz]`.

## Патчноуты
Админ выбирает канал командой `/patchnotes_channel` — бот сразу покажет там последний патчноут.
Дальше после каждого обновления и перезапуска бот сам пишет в этот канал новые записи из файла
`patchnotes.txt` (рядом с `bot.py`). Новая запись добавляется сверху:
```
## v6 | 09.11.2026 | Название обновления
- что появилось
- что исправлено
```
Номер (`v6`) должен быть новым — по нему бот понимает, что эту запись ещё не публиковал.
Посмотреть последний или любой прошлый патчноут — `/patchnotes`.

## Wortjagd — немецкие слова из 5 букв (/wort)
Нужно угадать немецкое слово из 5 букв за 6 попыток. После каждой догадки буквы подсвечиваются:
🟢 — на своём месте, 🟡 — есть в слове, но в другом месте, ⚫ — такой буквы нет. Буквы ä, ö, ü можно.
Играют в **мини-приложении Discord** — `/wort` или кнопка «Играть!» в чате открывает игру окном внутри Discord.
- **Слово дня** — одно на весь сервер, сыграть можно раз в день. За победу монеты: с 1-й попытки 500,
  дальше 350 / 250 / 150 / 100 / 50.
- **Кто ещё играет:** слева сверху в игре — аватарки и цвета догадок (без букв) всех, кто сегодня играет
  в слово дня на сервере. Обновляется раз в 2 секунды.
- **Только настоящие слова:** догадка принимается, если слово есть в `config/german_words.txt` или в немецком
  Викисловаре (бот проверяет и запоминает ответ). Выдуманные сочетания вроде «KZRZE» не засчитываются.
- **Картинка в чате:** когда кто-то начинает слово дня, бот присылает картинку «Wortjagd №…» с аватарками и
  полями всех игроков (только цвета, без букв) и кнопкой «Играть!». После каждого хода картинка обновляется.
  Первый игрок за день получает в чат итоги вчерашнего дня: сколько дней подряд сервер играет 🔥, кто с какой
  попытки отгадал (👑 — лучшие) и вчерашнее слово под спойлером. Выключить — `announce = off`.

Слово дня бот выбирает из `config/german_words.txt` (~550 слов), их можно дописывать без перезапуска.
Награды, часовой пояс смены слова и проверка слов (`check_words`) — `settings.ini`, раздел `[wortspiel]`.

### «5 букв» — русские слова (/slovo)
Та же игра, но с русскими словами: `/slovo` открывает мини-приложение сразу на ней. Внутри игры можно
переключаться между **DE** и **RU** — партии не сбрасываются. Русское слово дня своё, отдельное от немецкого:
можно сыграть в обе игры и получить награды за обе. Буква ё считается как е.
Слова принимаются из `config/russian_words.txt` (~490 существительных) и из русского Викисловаря.
В Викисловаре есть не все формы слов, поэтому надёжнее писать существительные в начальной форме («кошка», а не «кошки»).
В чате у неё своя картинка «5 букв №…» и свои итоги дня. Настройки — `settings.ini`, раздел `[slovo]`
(часовой пояс по умолчанию — Москва).

**Настройка мини-приложения** (один раз):
   1. https://discord.com/developers/applications → ваше приложение → **OAuth2**: скопируйте **Client Secret**
      и добавьте в `start.bat` строку `set DISCORD_CLIENT_SECRET=...` (никому не показывать!).
      Там же в **Redirects** добавьте `https://127.0.0.1` (Discord требует хотя бы один адрес).
   2. Бот при запуске поднимает маленький веб-сервер на `http://127.0.0.1:8080` (порт — `settings.ini`,
      раздел `[miniapp]`). Discord должен достучаться до него из интернета — через туннель. Проще всего
      **cloudflared**: скачать с https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
      и запустить рядом с ботом `cloudflared tunnel --url http://localhost:8080`. Он напишет адрес вида
      `https://что-то.trycloudflare.com`.
      Такой быстрый туннель меняет адрес при каждом запуске — для постоянного адреса нужен именованный
      туннель Cloudflare (свой домен) или бесплатный статический домен ngrok.
   3. В Developer Portal → **Activities → URL Mappings**: в строку с префиксом `/` впишите адрес туннеля
      **без** `https://` (например, `что-то.trycloudflare.com`).
   4. **Activities → Settings**: включите **Enable Activities**. Discord сам создаст команду запуска приложения.
      Там же в **Supported Platforms** включите **Web** (это и приложение на ПК), **iOS** и **Android** —
      иначе на неотмеченных устройствах будет ошибка 50231 «not configured to support the user's current client platform».
   5. Перезапустите бота. Теперь `/wort`, `/slovo` и кнопка «Играть!» открывают мини-приложение.
      Ещё его можно запустить из меню приложений в голосовом канале или чате.

## Утренние и вечерние сообщения
Включаются в Discord командой `/daily_setup`: выбрать канал, часовой пояс и время (по умолчанию 08:00 и 22:00).
Команду видят только те, у кого есть право «Управлять сервером». Проверить сразу — `/daily_test`, выключить — `/daily_off`.
Тексты пишет ИИ (по запросу в день на каждое сообщение); без ключа Gemini бот берёт запасные факты.

## Случайные реплики в чат
Раз в 20 минут бот «бросает кубик» и с шансом 5% сам пишет короткую реплику по теме разговора — шутку,
мнение или факт. Пишет только в канал, где люди общались за последние 20 минут, и не пишет, если последнее
сообщение там его собственное. Если тема неприличная или сказать нечего — промолчит.
Настройки — `settings.ini`, раздел `[chatter]`: `chance_percent` (0 — выключить) и `interval_minutes`.
Каждая реплика тратит один запрос к Google.

## Если треки перестали находиться
YouTube часто меняется — обновите yt-dlp и перезапустите бота.

Windows:
```
py -m pip install -U "yt-dlp[default]"
```
Linux:
```bash
cd ~/musicbot && source venv/bin/activate
pip install -U "yt-dlp[default]"
```
